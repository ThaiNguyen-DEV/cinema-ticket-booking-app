# PlantUML Diagrams

This folder contains PlantUML diagrams for the Cinema Ticket Booking App.

## Files

- `01-use-case.puml` - Customer and admin use cases
- `02-navigation-flow.puml` - App navigation flow
- `03-component-architecture.puml` - High-level component architecture
- `04-booking-sequence.puml` - Customer booking sequence
- `05-admin-flow.puml` - Admin mock data flow
- `06-data-model.puml` - Local mock data model

## Render Command

If PlantUML is installed locally:

```bash
plantuml docs/diagrams/*.puml
```

You can also paste each `.puml` file into a PlantUML online renderer.
